\begin{abstract}
This report describes version 6 of an event-camera time-to-collision research
pipeline. The revision does not claim state of the art. It first reconstructs
the historical Event-JEPA baseline exactly, separates that historical anchor
from a matched architecture control, and implements staged tests for dense
patch interaction, task-specific Attention Residuals, temporal delta memory,
object geometry, ego-motion, and a local Garl-TTC replica. The historical
checkpoint is reproduced byte-for-byte on its original cache and obtains
$0.322892$~s validation MAE, $0.584432$~s RMSE, and $8.1554\%$ mean relative
error. FlowMimic-style global auxiliary losses are retained only as a negative
result because they degrade multi-seed MAE.

The new components have passed unit and integration tests, but their small
smokes are explicitly non-promotable. Version 6 therefore defines a staged
screen, five-fold grouped cross-validation, and three-seed confirmation before
any external evaluation. The official Benchmark-10 remains sealed. The main
contribution at this stage is an auditable experimental basis rather than a
performance claim.
\end{abstract}

\section{Scope and claim boundary}

The project estimates continuous TTC from asynchronous event streams and,
conditionally, RGB and causal navigation. The long-term hypothesis is that
preserving dense spatial evidence, isolating the target object, and embedding
physical expansion in the output path can outperform regression from a pooled
scene embedding. This hypothesis is not yet accepted by the evidence.

The data inventory is closed:
\begin{itemize}
  \item EvTTC-32 is the only official TTC supervision source;
  \item eAP train-40 is reserved for later non-TTC pretraining;
  \item Benchmark-10 is an external sealed evaluation set;
  \item pseudo-TTC is never treated as ground truth.
\end{itemize}

\section{Matched architecture protocol}

The learned Core arms are:
\begin{itemize}
  \item \texttt{A0\_MATCHED\_GLOBAL}, the object-cache global control;
  \item \texttt{A1\_MATCHED\_DENSE\_BLOCK}, delayed pooling;
  \item \texttt{A2\_MATCHED\_DENSE\_ATTNRES}, depth routing by task;
  \item \texttt{K1\_OBJECT\_KDA}, temporal delta memory.
\end{itemize}

The fairness audit requires identical sample IDs, backbone hash, common head
hash, train and validation counts, optimizer, learning rate, weight decay,
maximum epochs, log-TTC loss, and early stopping. Actual completed epochs may
differ only through the shared stopping rule.

Core and Garl write separate stage roots:

  core/fold-<n>/matrix_summary.json
  garl/fold-<n>/matrix_summary.json
\end{lstlisting}
This prevents the previous summary collision while retaining individual run
directories.

\section{Dense spatial and temporal design}

\subsection{Patch Policy}

Patches from one timestamp communicate bidirectionally before any temporal
compression. Causality exists between time blocks, not between arbitrary
patches inside a frame. Pooling before target localization is forbidden in the
dense arm. This implements the dense representation principle motivated by
Patch Policy~\cite{patchpolicy2026}.

\subsection{Attention Residuals}

Mask, motion, geometry, and risk tasks independently retrieve features from
embedding and block outputs. Keys are RMS-normalized so a layer cannot dominate
by scale; the mixed values remain the original features. A permanent
greater-than-90\% weight on one layer is treated as collapse.

\subsection{Temporal delta memory}

The KDA candidate follows the delta-recurrence principle described by Kimi
K3~\cite{kimik32026}, but is restricted to the temporal axis. Spatial
interaction is resolved first. KDA is optional and must show either a precision
gain, a material memory reduction, or a longer effective horizon.

\section{Local Garl-TTC baseline}

Garl-TTC is implemented from the public source associated with the eAP
work~\cite{eapgarl2026}. The audited local contract uses three timestamps at
100~ms cadence, RGB endpoints, two event intervals, 20 time planes per
interval, and a common 128-by-128 endpoint square crop. RGB and event ResNet-50
branches can be trained for direct regression or learned height ratio (LHR).
Late fusion initializes its branches from the corresponding unimodal LHR
checkpoints. A foreground decoder produces four 256-by-256 logits during
training and is absent from inference.

EvTTC does not expose the original eAP 3D visible-height target. The local
adapter therefore supervises visible box height after the shared crop. Results
must be reported as a local architectural replica, not official eAP parity.

\section{Object geometry}

For apparent scale $s$, inverse-TTC at the current endpoint is
\begin{equation}
q_t = \frac{s_t/s_{t-\Delta t}-1}{\Delta t}.
\end{equation}
Height, square-root area, and affine expansion all use the latest valid pair.
The affine solver separates translation, radial expansion, and in-plane
rotation through weighted least squares. Event contrast evaluates a bounded
constant-approach warp only inside the object support. Auxiliary metadata
channels are excluded from the event calculation.

The training-free bbox oracle reports each expert and a deterministic
confidence mixture. It is an upper-bound diagnostic and not a bbox-free model.

\section{Ego-motion}

The EvTTC format states that integrated navigation attitude, position, and
velocity live in a world coordinate system~\cite{evttc2024}. Local auditing
shows velocity components ordered north, east, up and heading in degrees. The
heading agrees with geodetic displacement. Velocity is transformed through the
documented rigid chain
\begin{equation}
T_{\mathrm{event}\leftarrow\mathrm{nav}} =
T_{\mathrm{event}\leftarrow\mathrm{RGB}}
T_{\mathrm{RGB}\leftarrow\mathrm{LiDAR}}
T_{\mathrm{LiDAR}\leftarrow\mathrm{nav}}.
\end{equation}
The lever-arm velocity of the event-camera origin is included when heading
changes.

For a past point with causal depth, full planar camera-pose compensation uses
\begin{equation}
P_c = R_{c\leftarrow p}P_p - \Delta C_c.
\end{equation}
The boxes are reprojected with event-camera intrinsics. Ego closing contributes
$q_{\mathrm{ego}}=v_z/Z$. Translation is not observable from velocity alone:
depth is required. Consequently, official EvTTC distance is allowed only for
an oracle or teacher. A deployable arm must replace it with causal predicted
depth and be re-evaluated.

\section{Efficiency and storage}

The consumer hardware target has approximately 12.8~GB VRAM and 32~GB RAM.
Training uses BF16, pinned memory, persistent workers, prefetch, and gradient
accumulation. The Garl ResNet-50 screen uses microbatch 8 with accumulation 16;
the foreground arm uses microbatch 1 with accumulation 128. The geometric
solver remains FP32.

No full eAP voxel cache, full-resolution SAM logits, all-layer DINO cache, or
bulk TAR extraction is permitted. A run retains at most \texttt{best},
\texttt{last}, and \texttt{weights\_only}. Core and Garl caches are compressed
and stage-specific.

\section{Limitations and next steps}

No new component has a valid Screen or grouped-CV improvement yet. The Garl
ResNet-50 topology is tested, but its real screen remains pending. Translation
compensation is not deployable until depth is predicted. eAP is incomplete and
has no official TTC labels. Benchmark-10 has not been opened.

The next actions are: execute Core Screen, execute Garl Screen, promote only
arms passing their gates, run five-fold CV, repeat at most two finalists over
three seeds, and freeze before any external inference. These restrictions
preclude a current SOTA or safety claim.
