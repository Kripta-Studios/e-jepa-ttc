  uid=10_14 StaticText "The GarlTTC benchmark focuses on object TTC estimation. Participants predict a scalar TTC value for each annotated object-centered RGB-event temporal window. The benchmark follows the paper setting for evaluating geometry-aware representation learning, where object TTC is related to visual object-height changes and event-enhanced features help improve perception under challenging illumination. The released Garl-TTC model is designed for fast object TTC estimation and is reported in the paper as operating at 200 FPS."
