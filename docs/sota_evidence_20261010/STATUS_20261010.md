## Ingeniería y limitaciones

El piloto aislado conserva 12 consultas TRAIN40 vistas por el profesor. Sus
medianas posteriores al primer query son 82,345 ms para H8 warp graph fixed,
120,228 ms para Garl con entrada nativa y 36,806 ms para Garl con optimizaciones
exactas y captura GPU. Hay compilación inicial y colas altas: no es garantía de
tiempo real. Las filas originales y fallos parciales quedan en evidence/streaming.

La mejora de ingestión compacta está activa por defecto; la segmentación extra
de paquetes sigue opcional. El benchmark CPU no demuestra una mejora proporcional
del tiempo total. Véase [informe generado](STREAMING_OPTIMIZATION.md).
