# Reglas especializadas de ejecución

No sustituir el AGENTS.md existente. Integrar estas reglas en un documento de la
campaña y enlazarlo desde el prompt; no construir otro framework de agentes.

**Paridad:** seguir eventos x/y/t/p hasta la fase emitida. Equivalencia algebraica
no equivale a redondeo idéntico. Conservar normalización por ventana y conteos.

**Experimentos:** fijar datos, slots, presupuesto, comparadores y criterios antes
de outputs. Pérdidas por consulta; secuencias como unidades. Un fallo operativo no
es negativo científico. Replicar para aclarar una señal práctica, no para forzar p<0.05.

**Coste:** separar lectura, ROI, voxel, productores, transferencias, cabeza y
availability. No atribuir la velocidad de una cabeza al sistema AEB. Garl necesita
su encoding nativo y su propio contrato temporal.

**Recuperación:** fragmentos ligados a inputs y protocolo, progreso durable,
verificación fuerte en boundaries y detección de cambios. No repetir una admisión
completa por cada draw; no eliminarla para acelerar. Declarar el alcance del bundle.
