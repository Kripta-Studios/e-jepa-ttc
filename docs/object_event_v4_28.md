# Object Event v4.28 — posterior-supervised multiscale event correlation

V4.27 establishes that an explicit event-native height-ratio matcher is viable but not yet strong enough to open development-validation: grouped OOF reaches Pearson 0.603, log-height-ratio Pearson 0.592, negative accuracy 0.652 and negative-track macro accuracy 0.674. The failure is not binary. Four of the five original gates are close, while the largest remaining deficit is global correlation and magnitude calibration.

The v4.27 posterior is also extremely diffuse: the normalized scale entropy remains close to one throughout training, while the OOF prediction standard deviation is only about 61% of the target standard deviation. This produces a systematic shrinkage of large expansions toward zero. V4.28 therefore changes the supervision of the matcher itself rather than merely increasing the LHR loss: each sample receives a Gaussian soft target over the physically meaningful log-scale candidate grid, optimized by KL divergence. This forces the correlation volume to localize the correct scale instead of merely moving its soft-argmax mean.

V4.28 evaluates two fixed hypotheses under the same grouped OOF protocol. `profile_posterior` keeps the v4.27 vertical-profile matcher and isolates the posterior-supervision hypothesis. `spatial_rotation_posterior` preserves the full 2-D projected event feature map, uses all three event steps through the frozen v4.8 temporal projection, aligns soft event/foreground centroids, and marginalizes a small rotation nuisance while searching scale. The latter is motivated by the known sensitivity of pure height-ratio TTC to lateral/rotational image motion.

Both arms remain event-only at inference. Boxes and visible heights are training-only supervision. All 18 OOF trainings (2 arms x 3 seeds x 3 sequence folds) run before selection. Development-validation is materialized only if the all-seed OOF champion both clears absolute gates and improves over the sealed v4.27 OOF record. Only the fixed champion is then trained on full development-train and evaluated once. Official eAP test and EvTTC remain sealed.
